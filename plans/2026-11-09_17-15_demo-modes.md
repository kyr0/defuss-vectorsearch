# Plan: demo modes (reranker alone, embedder alone, fused) and a recall tab per mode

Tick a milestone `- [x]` only when its proof passes, then run `verify` on that milestone's scope.
Human requests (2026-11-09): the demo selects its mode with icon tabs: only the 1.5M reranker (the default), only
Winzling, or both fused. The recall card gets a second tab bar for the modes, an average bar and a "Target languages only" switch, and opens on
Fused at R@25, the hero's figure. The page calls the
models `kyr0/Winzling-embed` and `kyr0/Winzling-reranker`. The reranker's passage token vectors are prebuilt and
downloaded as a Brotli file; a "Re-embed the index" button encodes them in the browser to show what that costs.

## Evidence (probes 2026-11-09)

VERIFIED:

- `tmp/colbert-all-probe.ts` (1.5M q8, 2,000 bench passages): encoding takes 6.9 s native and 12.9 s WASM in Node.js;
  180,626 token vectors, 92.5 MB as float32; a query's MaxSim over all of them takes ~560 ms.
- `tmp/mode-probe.ts` (Chromium): encoding the 2,000 passages in the browser takes 16.4 s.
- `tmp/maxsim-probe.ts`: four accumulators speed MaxSim up by 25% in V8, from 470 to 355 ms, and 2× in Bun; not worth
  changing the library's tested `maxSim`.
- `tmp/token-store-probe.ts` (450 target-language queries): Brotli sizes and recall per stored precision.

  | Precision | Brotli | R@1 | R@5 | R@10 |
  |---|---:|---:|---:|---:|
  | float32 | 85.6 MB | 68.0 | 83.8 | 86.9 |
  | float16 | 42.1 MB | 68.2 | 83.8 | 86.9 |
  | int8 | 21.4 MB | 68.4 | 83.8 | 86.9 |
  | int4 | 8.2 MB | 67.3 | 83.8 | 87.3 |

- `tmp/colbert-demo-probe.ts`: the reranker alone ranks the English and German first example queries' gold passage
  first and puts the Giza passage first for both pyramid questions.
- The Hugging Face repos `kyr0/Winzling-embed` and `kyr0/Winzling-reranker` do not exist (API 401): display names.
- Chromium rejects Cache API keys with a `file:` scheme, so the token vectors are cached under a fixed https key.

## Decisions

- The token vectors ship as int4 with a scale per token (`scripts/docs/token-format.ts`, 8.5 MB with scales and
  header): R@5 equals float32, R@1 drops 0.7 points, at 13 MB less than int8.
- `make bench` gains `runRerankerBench` (Node.js and Chromium), stored as `environments.<env>.reranker` (schema v3).
- Nested tabs in the recall card: defuss-shadcn 0.9.13 switches panels by `aria-controls` id, so no script.
